# ✅ Full-Stack Task Manager

This is a **full-stack task management application** built using the **MERN Stack (MongoDB, Express.js, React, Node.js)** with **Redux Toolkit** for efficient state management. The app allows users to **create, update, delete, and manage tasks** seamlessly, along with **task prioritization, due dates, and analytics**.

## 🚀 Features  
- 📝 **Task Creation & Management** – Add, edit, and delete tasks easily.  
- ✅ **Task Status Tracking** – Mark tasks as completed or pending.  
- 🔐 **Authentication & Authorization** – Secure user login using JWT.  
- 🌐 **RESTful API** – Backend built with Express.js and Node.js.  
- 📦 **Redux Toolkit Integration** – Manages global state efficiently.  
- 📊 **User Dashboard & Task Analytics** – Visual insights into task progress.  
- ⏳ **Task Prioritization & Due Dates** – Set deadlines and priorities for better organization.  
- 🔔 **Real-time Notifications** – Stay updated with task reminders.

## 🚀 Getting Started  

### 1️⃣ Clone the Repository  
```sh
git clone https://github.com/your-username/task-manager.git
cd task-manager
```

### 2️⃣ Install Dependencies  
#### Backend  
```sh
cd server
npm install
```

#### Frontend  
```sh
cd client
npm install
```

### 3️⃣ Run the Application  
#### Start Backend  
```sh
cd server
npm start
```
#### Start Frontend  
```sh
cd client
npm run dev
```
